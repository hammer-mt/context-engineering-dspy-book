# Project instructions

## Model identifiers

- The model identifiers in this repository are lifted from the printed book, *Context Engineering with DSPy*. In notebooks and code examples that reproduce the book's listings, keep them exactly as printed. Do not replace, normalize, or "correct" them based on training data, external documentation, provider listings, or local availability.
- This keeps the repository in step with the book. It is not a rule about which models readers should use: anyone running the examples is free to swap in another model by changing the model string.
- If a printed model cannot be run in the current environment, keep the identifier and report the limitation as an environment constraint, not as an error in the book.
- Only change a printed model identifier in the repository when the author asks for a different model or for a compatibility fallback.
